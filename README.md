# HYPERBOREA — приложение для ПК

Приложение для Windows с сайтом HYPERBOREA внутри. Работает без интернета и без VPN.
Интернет нужен только для отправки карточек в Telegram: они идут через сервер сайта.

## Где что лежит

- `main.js` — само приложение: окно, загрузка файлов сайта, пересылка карточек на сервер.
- `scripts/copy-site.mjs` — копирует свежую версию сайта из папки проекта в `site/`.
- `fonts/` — шрифт Press Start 2P (лицензия OFL), чтобы он был и без интернета.
- `release/` — готовый установщик `HYPERBOREA-Setup-<версия>.exe` (появляется после сборки).

## Команды

- `npm start` — запустить приложение для проверки, без установки.
- `npm run build` — взять свежий сайт и собрать новый установщик в `release/`.

Перед новой сборкой поднимите номер `version` в `package.json`.

Клавиши в приложении: F11 — полный экран, Ctrl+R — перезагрузить.
