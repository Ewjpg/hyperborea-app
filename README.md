# HYPERBOREA — приложение для ПК и Android

Приложение для Windows и Android с сайтом HYPERBOREA внутри. Работает без интернета и без VPN.
Интернет нужен только для отправки карточек в Telegram: они идут через сервер сайта.

## Где что лежит

- `main.js` — приложение для ПК: окно, загрузка файлов сайта, пересылка карточек на сервер.
- `android/` — приложение для Android: то же самое, только на телефоне.
- `scripts/copy-site.mjs` — копирует свежую версию сайта из папки проекта в `site/`.
- `scripts/release.mjs` — выпуск обновления (см. ниже).
- `scripts/android-key.mjs` — ключ подписи для Android (см. ниже).
- `.github/workflows/android.yml` — сборка APK для Android на GitHub.
- `fonts/` — шрифт Press Start 2P (лицензия OFL), чтобы он был и без интернета.
- `release/` — готовый установщик `HYPERBOREA-Setup-<версия>.exe` (появляется после сборки).

## Команды

- `npm start` — запустить приложение для ПК для проверки, без установки.
- `npm run build` — взять свежий сайт и собрать новый установщик для ПК в `release/`.

- `npm run release` — выпустить обновление: поднять версию, собрать установщик для ПК и APK для Android и выложить на GitHub.
  Все установленные приложения найдут его при следующем запуске (или в течение 2 часов, если уже открыты).
  `npm run release -- minor` — для крупного обновления (1.1.0 → 1.2.0).
  Если выпуск оборвался на середине, он остаётся черновиком: `npm run release -- current` доделает его.

Обновления лежат здесь: https://github.com/Ewjpg/hyperborea-app/releases
Журнал проверки обновлений на компьютере: `%APPDATA%\HYPERBOREA\updates.log`.

Клавиши в приложении для ПК: F11 — полный экран, Ctrl+R — перезагрузить.

## Android

APK собирает GitHub, поэтому Android Studio на компьютере не нужна. `npm run release` сам запускает
сборку, ждёт её (обычно 5–10 минут) и публикует выпуск, только когда в нём есть и установщик для ПК, и APK.
Сайт для Android берётся из установщика для ПК того же выпуска, так что версии всегда одинаковые.

**Как поставить на телефон:** открыть на телефоне https://github.com/Ewjpg/hyperborea-app/releases/latest,
скачать `HYPERBOREA-<версия>.apk` и открыть его. Телефон попросит разрешить установку из этого
источника (браузера) — разрешить. Нужен Android 7 или новее.

**Обновления:** приложение само проверяет новые версии при запуске и раз в 2 часа и предлагает
«Обновить» — скачивает новую версию и открывает установку. В первый раз телефон попросит разрешить
приложению HYPERBOREA устанавливать приложения. Данные (черновики, настройки) при обновлении сохраняются.

**Ключ подписи — важно.** Обновление ставится поверх старой версии, только если обе подписаны одним ключом.
При первом `npm run release` ключ создаётся сам и кладётся в два места:
- в секреты репозитория на GitHub (Settings → Secrets and variables → Actions) — им подписывает сборка;
- копией в папку `HYPERBOREA-android-key` в домашней папке (`C:\Users\<имя>\HYPERBOREA-android-key`).

Сохраните копию этой папки (флешка, облако) и никому её не пересылайте. Если ключ потеряется,
новые версии не встанут поверх старой: всем придётся удалить приложение и поставить заново.
`npm run android-key` — положить ключ из этой папки обратно в секреты GitHub (или создать, если его нет нигде).

**Как устроено:** сайт лежит внутри APK и открывается во весь экран. Кнопка «Назад» работает как Escape
на ПК — закрывает открытый раздел; на главном экране сворачивает приложение. Ссылки на другие сайты
открываются в браузере телефона. Карточки уходят на сервер сайта так же, как с ПК.

**Проверка:** при изменениях в папке `android/` GitHub собирает приложение и проверяет его на эмуляторе
Android 15 (`android/ci/smoke-test.sh`): сайт открывается, файлы и музыка грузятся, сервер отвечает,
«Назад» работает, обновление скачивается и ставится. Снимки экрана — в разделе Artifacts на странице
запуска во вкладке Actions.

Папку `android/` можно открыть и в Android Studio: сайт она берёт из `site/` (сначала `npm run copy-site`).
