# HYPERBOREA — приложение для ПК

Приложение для Windows с сайтом HYPERBOREA внутри. Работает без интернета и без VPN.
Интернет нужен только для отправки карточек в Telegram: они идут через сервер сайта.

## Где что лежит

- `main.js` — само приложение: окно, загрузка файлов сайта, пересылка карточек на сервер.
- `scripts/copy-site.mjs` — копирует свежую версию сайта из папки проекта в `site/`.
- `site-updates/` — изменения для папки сайта; вносятся командой `npm run site-update`.
- `fonts/` — шрифт Press Start 2P (лицензия OFL), чтобы он был и без интернета.
- `release/` — готовый установщик `HYPERBOREA-Setup-<версия>.exe` (появляется после сборки).

## Команды

- `npm start` — запустить приложение для проверки, без установки.
- `npm run build` — взять свежий сайт и собрать новый установщик в `release/`.
- `npm run site-update` — внести в папку сайта обновления из `site-updates/` (подробнее ниже).

- `npm run release` — выпустить обновление: поднять версию, собрать и выложить на GitHub.
  Все установленные приложения найдут его при следующем запуске (или в течение 2 часов, если уже открыты).
  `npm run release -- minor` — для крупного обновления (1.1.0 → 1.2.0).

Обновления лежат здесь: https://github.com/Ewjpg/hyperborea-app/releases
Журнал проверки обновлений на компьютере: `%APPDATA%\HYPERBOREA\updates.log`.

Клавиши в приложении: F11 — полный экран, Ctrl+R — перезагрузить.

## Обновления сайта

Сайт лежит на компьютере (папка указана в `scripts/site-path.mjs`, другую можно задать через `HYPERBOREA_SITE`).
Готовые изменения к нему лежат в `site-updates/`, каждое в своей папке.

- `npm run site-update` — внести в папку сайта то, что ещё не внесено. Каждое обновление вносится один раз.
  Прежние версии заменённых и удалённых файлов копируются в `site-backups/<дата>/`.
  Если какой-то файл на компьютере уже меняли после версии 1.1.3, вносятся только правки (для этого нужен git).
  Если правки не подходят, ничего не меняется и скрипт пишет, какие файлы мешают.
- `npm run site-update -- --check` — показать, что будет сделано, ничего не меняя.

Сейчас в `site-updates/` лежит «Минами Син вместо Хейса Мюллера» (карточка 04: хиганбана, красная тема, новая музыка).
Трек темы — Run Up (Jun Murayama) — в репозиторий не входит. Его нужно передать при внесении обновления:

    npm run site-update -- --music "C:\путь\к\Run Up.mp3"

Другой формат (WAV, M4A и т. д.) переведётся в MP3, если установлен ffmpeg.
Потом: `npm start` — посмотреть, `npm run release` — выпустить. Если обновление ещё не внесено или нет трека,
`npm run build` и `npm run release` предупредят об этом.
